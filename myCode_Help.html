Project Code Dictionary

A quick reference list of the exact HTML tags, JavaScript functions, and CSS properties used across your entire Trading System.

1. HTML Tags & Attributes Used

HTML Tag / Attribute Where & Why it is used in your project
<div class="page-container"> Universal wrapper class to give every page an identical height, width, font size, and premium background aesthetic.
<div class="trade-container"> Specific 3-column grid container used explicitly for the Trade Setup flowchart to prevent CSS layout conflicts on other pages.
<header>, <aside>, <main> Semantic tags injected natively into every HTML file to create the standard Multi-Page Application layout.
<link>, <script> Used to connect your external .css and .js files to your HTML pages.

2. JavaScript Logic & Functions Used

JavaScript Function / Concept Where & Why it is used in your project
document.createElement('div') Used in analysis_2026.js to generate the 2026 calendar dynamically instead of writing hundreds of lines of HTML by hand.
.appendChild() Used to take the dynamically created calendar days and actually place them onto the screen.
new Date(year, month, 1) Used in the calendar to automatically calculate how many days are in a month and what day of the week it starts on.
document.querySelectorAll() Used to find all flowchart steps or navigation links so we can loop through them.
element.addEventListener('click') Used to listen for when you click on a step, a menu item, or a calendar date so the code can respond.
element.classList.add() / .remove() Used to temporarily add an active class to highlight the menu item you just clicked.
setInterval(..., 1000) Used in index.html to update the live digital clock every 1000 milliseconds (1 second).
fetch() & async/await Used to load massive CSV data files (like NIFTY_HOLC.csv) asynchronously without freezing the UI.
mousedown, mousemove Event listeners used to create the draggable floating window for the minute-by-minute HOLC data.
new Image().onload Used in analysis.js to silently check if a local image file exists in the background. If successful, it automatically highlights the available Option Strike buttons in green.
window.location.pathname Used in index.js to dynamically read the current URL in the browser and automatically highlight the correct sidebar menu item for any page.
Python Metadata Generation A backend preprocessing technique. We created generate_meta.py to crunch 48MB CSV datasets and output a lightweight JSON file, preventing the browser from freezing.

3. CSS Features & Layouts Used

CSS Feature / Rule Where & Why it is used in your project
position: sticky; top: 0; Used in analysis_2026.css to lock the "2026 Trading Journal" title to the top of the screen while you scroll down through the months.
backdrop-filter: blur(16px); Used in the Main Menu (manue.html) to create a beautiful "frosted glass" (glassmorphism) effect behind the dashboard options.
display: grid; Used heavily to split the screen into 3 columns, and to create the 7-day layout for the calendar.
overflow-y: auto; Applied to the .main-body container to ensure long pages can scroll vertically seamlessly within the unified layout structure.
z-index: 100; Used to ensure sticky headers or menus float above everything else, so calendar grid items don't overlap them.
linear-gradient() Used to give the flowchart boxes and the main page titles a beautiful, premium color blend.
transition:, :hover Used to make boxes pop out smoothly and change border colors when you hover your mouse over them.
:root { --variables } Used to define the dark mode color palette globally so they can be reused easily.
display: flex; flex-direction: row; Extensively used in analysis.html to create the horizontal grid rows for the Options Chain (CALL, STRIKES, PUT) and to flawlessly position the Chart and Option Images side-by-side.
height: 300px; overflow-y: auto; Used in the Analysis layout to lock a container's size and safely enable internal vertical scrolling when the grid content overflows.
